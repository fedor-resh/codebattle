# Один расчёт на ключ

Для каждого ключа из `keys` верните результат `work(key)` на той же позиции. Если ключ повторяется, `work` для него должна быть вызвана ровно один раз, а полученный результат нужно использовать для всех повторов.

Разные уникальные ключи должны вычисляться параллельно. `work` может занимать заметное время, поэтому последовательная обработка уникальных ключей не пройдёт скрытый тест по времени. Дождитесь завершения всех запущенных вычислений перед возвратом из функции.

Пустому входу соответствует пустой slice. Реализуйте `Solve(keys []int, work func(int) int) []int` в пакете `solution`.
