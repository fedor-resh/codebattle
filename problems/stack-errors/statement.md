# Стек с ошибкой

Допишите тип `Stack` с pointer-методами:

- `Push(value int)` кладёт число на вершину;
- `Pop() (int, error)` снимает верхний элемент. Если стек пуст, верните `0` и sentinel `ErrEmpty`.

Нулевое значение `Stack` должно быть готово к использованию. Проверяющая система вызывает методы напрямую и использует `errors.Is`, поэтому не удаляйте ошибку, тип и сигнатуры методов.

Готовая функция `Solve(commands []string) []string` выполняет команды `push N` и `pop`. Для успешного `push` она добавляет `ok`, для успешного `pop` — число строкой, для пустого стека — `err.Error()`. Некорректная команда даёт `ok` и не меняет стек.
