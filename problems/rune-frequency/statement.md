# Частоты символов

Дана строка `text`. Верните map, где ключ — один Unicode-символ в виде строки, а значение — количество его появлений в исходном тексте.

Регистр, пробелы и знаки препинания учитываются. Для пустой строки верните пустой map.

Реализуйте функцию `Solve(text string) map[string]int` в пакете `solution`.
