# Разбор конфигурации

Реализуйте `Parse(text string) (map[string]int, error)`. Конфигурация состоит из строк вида `key=value`. Пробелы вокруг ключа и значения нужно игнорировать. Пустые строки и строки, первый непробельный символ которых — `#`, являются комментариями и пропускаются.

Верните `ErrBadLine`, если непустая строка не содержит ровно одного знака `=` или ключ пуст. Верните `ErrDuplicate`, если ключ уже встречался, и `ErrInvalidValue`, если значение не является целым числом. Ошибки оборачиваются номером строки; проверяющая система использует `errors.Is`, поэтому не удаляйте sentinel-ошибки и не меняйте сигнатуру `Parse`.

`Solve` — готовая обёртка для judge. При успехе она возвращает отсортированные по ключу строки `key=value`, а при ошибке — slice из одного элемента с `err.Error()`.
