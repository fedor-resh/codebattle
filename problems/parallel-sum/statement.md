# Параллельная сумма

Вычислите сумму элементов `nums` с помощью пула из `workers` горутин. Передавайте работу через канал и дождитесь завершения всех workers с помощью `sync.WaitGroup`.

Если `workers <= 0`, используйте одного worker. Пустой массив имеет сумму `0`. Функция не должна оставлять запущенные или заблокированные горутины после возврата.

Реализуйте функцию `Solve(nums []int, workers int) int` в пакете `solution`.
