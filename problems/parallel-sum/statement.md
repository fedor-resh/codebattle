# Параллельная сумма

Вычислите сумму результатов `work(nums[i])` с помощью не более чем `workers` параллельных обработчиков. Проверяющая система передаёт функцию `work`, выполнение которой может занимать заметное время. Вызовите её ровно один раз для каждого элемента.

Если `workers <= 0`, используйте одного обработчика. Пустой массив имеет сумму `0`. Способ организации и синхронизации параллельной работы выбирайте сами.

Параллельность проверяется по времени выполнения медленных вызовов `work`: последовательное решение не укладывается в лимит скрытого теста.

Реализуйте функцию `Solve(nums []int, workers int, work func(int) int) int` в пакете `solution`.
