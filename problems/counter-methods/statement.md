# Счётчик с методами

Допишите тип `Counter` с pointer-методами:

- `Inc()` увеличивает значение на 1;
- `Add(delta int)` прибавляет `delta` (может быть отрицательным);
- `Value() int` возвращает текущее значение.

Нулевое значение `Counter` должно быть готово к использованию и иметь значение 0. Проверяющая система вызывает методы напрямую, поэтому не удаляйте тип и заготовки методов и не меняйте их сигнатуры.

Готовая функция `Solve(commands []string) []int` выполняет команды `inc` и `add N` и возвращает значение счётчика после каждой команды. Некорректная команда не меняет счётчик, но для неё также добавляется текущее значение.
