# Самый быстрый обработчик

Каждый элемент `delays` описывает работу отдельного обработчика. Запустите для каждого элемента `work(ctx, delays[i])` параллельно и верните индекс первого обработчика, вернувшего `true`. Если ни один не успел за `timeoutMS` миллисекунд, верните `-1`.

После получения результата или таймаута отмените общий `context.Context` и дождитесь завершения остальных обработчиков. `work` возвращает `false`, если обработка была отменена. Каждый обработчик должен быть запущен ровно один раз.

Все задержки неотрицательны и попарно различны. Для пустого `delays` или `timeoutMS <= 0` верните `-1`.

Способ синхронизации выбирайте сами. Проверка использует реально долгую функцию `work` и короткий дедлайн, поэтому последовательное решение получает неправильный ответ менее чем за 5 секунд.

Реализуйте функцию `Solve(delays []int, timeoutMS int, work func(context.Context, int) bool) int` в пакете `solution`.
