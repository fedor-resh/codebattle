# Конвейер фильтров

Дан интерфейс `Filter` с методом `Apply(int) int`. Реализуйте этот интерфейс для трёх типов из заготовки:

- `Add{Value: n}` прибавляет `n`;
- `Mul{Value: n}` умножает на `n`;
- `Clamp{Min: a, Max: b}` ограничивает число диапазоном `[a, b]`.

Проверяющая система проверяет соответствие интерфейсу и вызывает `Apply` напрямую. Не удаляйте интерфейс, типы и методы из заготовки и не меняйте их сигнатуры.

Готовая функция `Solve(nums []int, ops []string) []int` строит фильтры по строкам `add N`, `mul N` и `clamp MIN MAX`, затем применяет их к каждому числу слева направо. Некорректные операции пропускаются. Для `clamp` гарантируется `MIN <= MAX`.
