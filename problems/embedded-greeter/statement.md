# Встроенное приветствие

Встраивание в Go не даёт виртуальных методов: вызов метода на встроенном поле всегда использует реализацию этого поля.

Допишите типы из заготовки:

- `Base.Greet()` возвращает `Hello, {Name}`;
- `Shouty` встраивает `Base` и переопределяет `Greet()` как `HEY, {NAME}!`, где имя в верхнем регистре;
- `Polite` встраивает `Base` и возвращает `Please, ` плюс результат `p.Base.Greet()`. Вызывать `p.Greet()` нельзя: это бесконечная рекурсия.

Все три типа должны реализовывать интерфейс `Greeter`. Не удаляйте типы и методы из заготовки и не меняйте их сигнатуры.

`Solve(kinds []string, names []string) []string` уже собирает приветствия. Для каждого индекса `i` вид `kinds[i]` равен `base`, `shouty` или `polite`, а имя берётся из `names[i]`. Лишние элементы более длинного аргумента игнорируются.
