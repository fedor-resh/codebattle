# Двухступенчатый конвейер

Для каждого элемента `x` вычислите `stageB(stageA(x))` и верните результаты в том же порядке, в котором элементы находились в `nums`. Каждую функцию для каждого элемента нужно вызвать ровно один раз.

Организуйте вычисления как двухступенчатый конвейер: пока `stageB` обрабатывает результат одного элемента, `stageA` должна иметь возможность обрабатывать следующий. Стадии могут занимать заметное время, поэтому полностью последовательное решение не пройдёт скрытый тест по времени.

Пустому входу соответствует пустой slice. Реализуйте `Solve(nums []int, stageA func(int) int, stageB func(int) int) []int` в пакете `solution`.
