# Упорядоченный worker pool

Параллельно вычислите `work(nums[i])` с помощью не более чем `workers` обработчиков. Проверяющая система передаёт функцию `work`, выполнение которой может занимать заметное время. Вызовите её ровно один раз для каждого элемента.

Результаты должны находиться в том же порядке, что и исходные элементы, независимо от порядка завершения обработчиков. Если `workers <= 0`, используйте одного обработчика. Для пустого ввода верните пустой срез.

Способ синхронизации выбирайте сами. Параллельность проверяется по времени: последовательное выполнение медленных вызовов `work` не укладывается в лимит скрытого теста.

Реализуйте функцию `Solve(nums []int, workers int, work func(int) int) []int` в пакете `solution`.
