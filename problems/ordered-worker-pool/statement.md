# Упорядоченный worker pool

Параллельно вычислите квадрат каждого числа из `nums` с помощью пула из `workers` горутин. Результаты должны находиться в том же порядке, что и исходные элементы, независимо от порядка завершения workers.

Передавайте задания через канал и дождитесь всех workers с помощью `sync.WaitGroup`. Если `workers <= 0`, используйте одного worker. Для пустого ввода верните пустой срез.

Реализуйте функцию `Solve(nums []int, workers int) []int` в пакете `solution`.
