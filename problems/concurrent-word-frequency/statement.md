# Конкурентная частота слов

Параллельно обработайте каждое слово функцией `work` и подсчитайте частоту получившихся строк. Используйте не более `workers` одновременных обработчиков и вызовите `work` ровно один раз для каждого слова. Проверяющая система может передать функцию, выполнение которой занимает заметное время.

Если `workers <= 0`, используйте одного обработчика. Регистр символов учитывается. Для пустого ввода верните пустую map. Способ безопасного объединения результатов выбирайте сами.

Параллельность проверяется по времени выполнения медленных вызовов `work`: последовательное решение не укладывается в лимит скрытого теста.

Реализуйте функцию `Solve(words []string, workers int, work func(string) string) map[string]int` в пакете `solution`.
