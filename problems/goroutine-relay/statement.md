# Эстафета горутин

Запустите две горутины: одна должна добавлять слово `ping`, а вторая — слово `pong`. Синхронизируйте их каналами так, чтобы результат содержал `n` повторений строки `pingpong`.

Если `n <= 0`, верните пустую строку. Решение должно использовать горутины и каналы и не должно оставлять заблокированные горутины после возврата из `Solve`.

Реализуйте функцию `Solve(n int) string` в пакете `solution`.
