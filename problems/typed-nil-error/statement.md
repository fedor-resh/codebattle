# Typed nil

Исправьте `Validate(values []int) error`. Отрицательное число — ошибка: верните `*ValidationError` с индексом и значением первого такого элемента.

Если все числа неотрицательны, функция должна вернуть именно `nil`-интерфейс. Заготовка специально содержит классическую ловушку: переменная типа `*ValidationError` вставляется в `error`, и даже нулевой указатель даёт `err != nil`.

`Error()` уже nil-safe: не удаляйте тип, sentinel-поведение и сигнатуру `Validate`. Проверяющая система сравнивает результат с `nil` и использует `errors.As`.

`Solve(values []int) string` возвращает `ok` либо `err.Error()`.
