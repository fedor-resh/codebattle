# Database migrations

Миграции добавляются отдельными нумерованными SQL-файлами:

```text
000001_name.sql
```

Для простого MVP API применяет ещё не выполненные миграции при запуске и отмечает
их в `schema_migrations`. Перед production-развёртыванием это можно вынести в
отдельную команду без изменения самих SQL-файлов.
